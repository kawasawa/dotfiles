# configs

設定ファイル類とそのパーミッションは chezmoi で管理する。  
(システムの制御を伴うような高度な操作は Ansible に任せる。)

## プレフィックス

- `dot_`: 先頭ドットへの変換する (`dot_zshrc` → `.zshrc`)。
  - 逆に先頭ドットで記載した場合は chezmoi の管理から外れる。
- `exact_`: 配置先に chezmoi 管理外のファイルがあればそれらを削除する。
- `symlink_`: 配置先にシンボリックリンクを作る。
  - このファイルの中身はリンク先パスとして解釈される (従ってファイル本体は別に用意する)。
  - 配置先で行われた変更がリポジトリの実体へ即座に書き戻されるため、端末側で試行錯誤する設定には向かない。
- `modify_`: 配置先の現在の内容を取得し書き換える。
  - アプリ自身も頻繁に書き込むステートファイルなどにおいて、キーだけを管理する等の用途で使われる。
  - 中身に `chezmoi:modify-template` を含めるとテンプレートとして評価され、現在の内容が `.chezmoi.stdin` で渡る (`.tmpl` は付けない)。
- `run_after_`: `chezmoi apply` 後にキックされるスクリプト。
  - 複数存在する場合はファイル名の順に実行される。
- `run_onchange_`: 内容が変わった時のみ実行されるスクリプト。
  - ハッシュコメントを埋め込むことで「特定のファイルの変更時のみ実行する」処理を書ける。
  - 非ゼロ終了した場合、次回の apply 時に再試行される。

### パーミッション

- プレフィックスで配置先のパーミッションを指定可能 (umask 022 の場合)。
  - 逆に、ファイルの実際のモードは参照されない。
  - 既存の権限を変えたくない場合は、まず `chezmoi apply --dry-run -v` で確認すること
    - 例えば `~/Library` は macOS が既定 700 を割り当てているため `private_` が必要。

| プレフィックス      | ファイル | ディレクトリ | 用途                       |
| ------------------- | -------- | ------------ | -------------------------- |
| (なし)              | 644      | 755          | 既定                       |
| `executable_`       | 755      | -            | 実行権限が必要なスクリプト |
| `private_`          | 600      | 700          | 他ユーザに見せない設定     |
| `readonly_`         | 444      | 555          | 書き換えを防ぐ設定         |
| `private_readonly_` | 400      | 500          | 上記の組み合わせ           |

## 特別なファイル

### [.chezmoiroot](../.chezmoiroot)

- chezmoi による配布対象のファイルを配置したルートディレクトリ (リポジトリ) を指定できる。
- リポジトリ外のファイルを配布する場合は `.tmpl` の `include` が使う。相対パスはルートディレクトリ起点で解決され、配置先には実体ファイルが作られる。
  - `symlink_` とは異なり、端末側の変更がリポジトリに波及しない。
  - `chezmoi re-add` はテンプレートを拾わないため、退避経路は別途用意が必要 ([export.sh](../export.sh) が担当)。
- 実行時のカレントディレクトリは配置先 (`$HOME`) になるため、リポジトリ内のファイルを参照するには `.tmpl` にして `{{ .chezmoi.workingTree }}` を使う。

### [.chezmoi.toml.tmpl](./.chezmoi.toml.tmpl)

- chezmoi 自身にも設定ファイルがあり、それが本ファイル。
- `chezmoi init` 時に `~/.config/chezmoi/chezmoi.toml` へ展開される。
  - 以降も `init` のたびに再生成される (つまり端末側で行われた変更は失われる)。
- `sourceDir` はこのファイルが宣言する (従って `chezmoi init` が明示的に `--source` を渡す必要があるのは初回だけ)。

### [.chezmoiexternal.toml](./.chezmoiexternal.toml)

- `chezmoi apply` 時に外部から取得が必要なリソースを宣言できる。
- 取得済みのリソースは `refreshPeriod` が経過時に再取得される。
  - `file` はダウンロードキャッシュの mtime、`git-repo` は最後に clone / pull した時刻で判定される。
  - 未指定時は `0` として扱われ、初回取得以外では更新されない。
  - 即座に強制更新する場合は `chezmoi apply -R always` を使う。
